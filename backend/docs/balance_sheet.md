# 资产负债表 Balance Sheet

资产负债表展示公司在某一时间点的财务状况。

核心公式：

Assets = Liabilities + Shareholders' Equity

资产 Assets 是公司拥有或控制的资源，例如现金、应收账款、存货、设备和无形资产。

负债 Liabilities 是公司需要偿还的义务，例如短期借款、长期债务、应付账款和租赁负债。

股东权益 Shareholders' Equity 是资产扣除负债后属于股东的部分。

资产负债表可以用来分析公司的偿债能力、资本结构和财务稳定性。

例如，如果公司负债过高，即使收入增长，也可能面临较高的财务风险。
